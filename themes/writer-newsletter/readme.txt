A newsletter-style block theme: one narrow reading column, a dated list of posts and a subscribe box after every post.

== Description ==

Writer Newsletter is built for writers who publish regular issues. Everything sits in one narrow column (about 640px) so posts read like a letter.

* Header: site title, tagline and a Subscribe button.
* Home: a dated list of posts with excerpts, author and reading time.
* Single post: a large title, a byline with avatar, date and reading time, then a subscribe box, previous/next links and a short "From the archive" list.
* Archive: a simple one-line-per-post list with dates.
* Style variations: Default (light), Paper (warm light) and Night (dark).
* Patterns: dated post list, simple archive list, issue sign-off and an About page.

= Writer Subscribe =

When the Writer Subscribe plugin is active, the theme shows its form in a subscribe box after each post and in the footer, and adds a Subscribe button to the header. When the plugin isn't active those pieces don't render at all, so nothing is left behind. The form is styled through the plugin's `--wsub-*` custom properties, so it follows the active style variation.

= Reading time =

The reading time is a Paragraph block bound to the `writer-newsletter/reading-time` block bindings source (230 words a minute).
